# HTML Notes

HTML (HyperText Markup Language) is the standard markup language used to create the structure of web pages.

## 📌 Basic Structure of an HTML Document

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Web Page</title>
</head>
<body>

    <h1>Hello World</h1>
    <p>This is my first web page.</p>

</body>
</html>
```

## 🧩 Basic HTML Tags

| Tag             | Purpose                       |
| --------------- | ----------------------------- |
| `<html>`        | Defines the HTML document     |
| `<head>`        | Contains page information     |
| `<title>`       | Defines the page title        |
| `<body>`        | Contains visible page content |
| `<h1>` – `<h6>` | Defines headings              |
| `<p>`           | Defines a paragraph           |
| `<a>`           | Creates a hyperlink           |
| `<img>`         | Displays an image             |
| `<br>`          | Inserts a line break          |
| `<hr>`          | Creates a horizontal line     |
| `<ul>`          | Creates an unordered list     |
| `<ol>`          | Creates an ordered list       |
| `<li>`          | Defines a list item           |
| `<div>`         | Defines a block/container     |
| `<span>`        | Defines an inline container   |

## 🔗 Links

The `<a>` tag is used to create hyperlinks.

```html
<a href="https://example.com">Visit Website</a>
```

## 🖼️ Images

The `<img>` tag is used to display images.

```html
<img src="image.jpg" alt="Sample Image">
```

## 📝 Forms

HTML forms are used to collect information from users.

Common form elements include:

* `<form>`
* `<input>`
* `<label>`
* `<textarea>`
* `<select>`
* `<button>`

Example:

```html
<form>
    <label for="name">Name:</label>
    <input type="text" id="name">

    <button type="submit">Submit</button>
</form>
```

## 🎯 Learning Goals

* Understand HTML structure
* Learn commonly used HTML tags
* Create forms and links
* Add images and multimedia
* Build structured web pages
* Practice semantic HTML
