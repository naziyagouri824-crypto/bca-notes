# Git and GitHub Notes

These are my notes on Git and GitHub while learning version control and project management.

## 📌 What is Git?

Git is a distributed version control system used to track changes in files and manage different versions of a project.

It helps developers:

* Track changes
* Restore previous versions
* Work on different features
* Manage project history

## 📌 What is GitHub?

GitHub is a platform for hosting Git repositories online.

It helps developers:

* Store projects online
* Share code
* Collaborate with others
* Build a developer portfolio
* Manage projects using Git

## 🔗 Git vs GitHub

| Git                         | GitHub                                     |
| --------------------------- | ------------------------------------------ |
| Version control system      | Online platform                            |
| Works locally               | Works online                               |
| Tracks changes              | Hosts Git repositories                     |
| Created for version control | Provides collaboration and project hosting |

## 🧩 Important Git Concepts

* Repository
* Commit
* Branch
* Merge
* Clone
* Push
* Pull
* Remote

## 💻 Basic Git Workflow

```text
Working Directory
       ↓
     Stage
       ↓
     Commit
       ↓
     Push
       ↓
    GitHub
```
